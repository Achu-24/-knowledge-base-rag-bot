Machine Learning Fundamentals

Machine Learning is a field of Artificial Intelligence
that enables computers to learn from data.

There are three main types of Machine Learning:

1. Supervised Learning:
The model learns from labeled data.
Examples include spam detection and house price prediction.

2. Unsupervised Learning:
The model finds patterns in unlabeled data.
Examples include customer segmentation and clustering.

3. Reinforcement Learning:
The model learns through interaction with an environment
using rewards and penalties.

Training data is used to teach a machine learning model.
Testing data is used to evaluate its performance on unseen data.
